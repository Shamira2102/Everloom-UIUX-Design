## 📖 Overview

**Everloom** is a UI/UX design concept for a personal digital memory vault that helps users preserve meaningful moments and organize them for future access.

The concept explores how personal memories such as **photos, videos, letters, and voice notes** can be preserved through a thoughtful, privacy-conscious experience.

## 🧩 Problem Statement

Digital memories are often **scattered across multiple platforms**, making them difficult to organize, preserve, and intentionally pass on to others.

Everloom explores a more meaningful and structured approach to long-term digital memory management.

---

## 🎯 Design Goals
- ✅ Create a simple and intuitive memory-preservation experience
- 🗂️ Organize different types of memories in one place
- 👥 Provide clear control over recipients and access
- 🔒 Build trust through privacy-focused design
- 💜 Create an emotionally engaging user experience

---

## ✨ Key Features

| Feature | Description |
| 🏛️ **Digital Memory Vault** | A single, secure place for all personal memories |
| 🕰️ **Memory Timeline** | Browse memories chronologically with emotional context |
| 📸 **Multi-format Preservation** | Photos, videos, letters, and voice notes together |
| 👨‍👩‍👧 **Recipient Management** | Decide who receives which memory |
| 🔐 **Privacy & Access Controls** | Clear, transparent control over visibility and access |
| 🖱️ **Interactive Prototype** | Clickable end-to-end flow built in Figma |

---

## 🔄 Design Process

```
Research → Information Architecture → User Flow → Wireframes → UI Design → Prototyping
```

| Stage | Focus |
| 🔍 **Research** | Understanding how people store and share memories |
| 🗺️ **Information Architecture** | Structuring content types and access levels |
| 🔀 **User Flow** | Mapping the journey from upload to legacy sharing |
| ✏️ **Wireframes** | Low-fidelity layouts for structure and usability |
| 🎨 **UI Design** | Visual identity, components, and styling |
| 🧪 **Prototyping** | Interactive screens to test the experience |
